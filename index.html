‘4대 사회보험 가입자 가입내역 확인서’ 제출 안내

아래 절차에 따라 4대사회보험정보연계센터에서 ‘가입내역 확인서’를 발급하고, 웹팩스(WebFax)로 본교에 제출해 주시기 바랍니다.
01

제출방법

  1. “4대사회보험정보연계센터” 접속 바로가기
  2. [개인 비회원 로그인] 클릭 후 간편인증, 모바일 신분증 등으로 로그인
  3. [증명서발급] → [증명서 신청/발급] 메뉴 접속
    • 개인정보제공동의 후 [확인] 버튼 클릭
    • 증명서 발급 관련 안내 사항 확인 후 [확인] 클릭
  4. [확인] 클릭 후 이동된 “증명서 신청/발급” 페이지에서 아래 내용 확인 후 [신청] 버튼 클릭
    • 가입내역확인서 청구내역 : 체크 표시 확인
    • 확인자 이름 및 주민등록번호 앞자리 맞게 입력되었는지 확인
    • “근무중인 사업장”에서 [명칭] – 전체사업장 선택 확인
    사업자등록번호, 사업장관리번호 입력 X
    용도 – 확인용, 주민등록번호 뒷자리 표시 – 아니오 선택 확인
  5. [신청] 버튼 클릭 후 이동된 페이지의 [증명서 상세내역] 표에서 [처리여부] 4개 모두 “출력가능”으로 표기되었는지 확인
    [새로고침] 클릭하시면 처리여부가 갱신됩니다(일정 시간 소요)
  6. 페이지 아래 [출력] 버튼 클릭 후 나온 페이지의 왼쪽 위 [웹팩스] 버튼 클릭
    [전자증명서]는 전자지갑 전송으로, 본교는 확인할 수 없습니다
  7. [증명서 WebFax 전송] 창에 아래 팩스번호를 입력 후 [보내기] 클릭
    WebFax 전송 팩스번호
    0303-3440-2345
02

유의사항

  • ‘개인 비회원 로그인’ 시 간편인증 또는 모바일 신분증이 필요합니다.
  • ‘전체사업장’으로 선택해야 모든 가입 이력이 포함됩니다.
  • [처리여부]가 모두 “출력가능”으로 바뀐 후에 출력·전송해 주세요.
  • 반드시 웹팩스(WebFax)로 제출해야 하며, 전자증명서(전자지갑) 전송은 본교에서 확인할 수 없습니다.
  • 팩스번호(0303-3440-2345)를 정확히 입력했는지 확인 후 전송해 주세요.
본 안내문은 ‘4대 사회보험 가입자 가입내역 확인서’ 제출을 위한 참고용입니다.
